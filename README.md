## 팀에 작업 요청하기

현재 Codex 채팅에 다음처럼 요청하면 해당 역할의 기준으로 작업합니다.

- “기획 파트에서 다음 개선안을 검토해줘.”
- “디자인 파트에서 모바일 게임 화면을 개선해줘.”
- “T-01 모바일 핵심 흐름 점검부터 진행해줘.”
- “개발과 QA까지 완료하고 배포해줘.”

기본적으로 한 에이전트가 필요한 역할을 순서대로 수행합니다. 실제 다중 에이전트 분담은 별도 요청 시 적용합니다. 이 문서 자체가 작업을 예약하거나 자동 실행하지는 않습니다.

## 개발과 저장

`docs/`는 GitHub Pages 공개 폴더입니다. 제품팀 문서는 `team/`에 두며 서비스 메뉴에 노출하지 않습니다. 목표·게임 최고 기록·게시판은 브라우저에 저장되며 다른 사용자나 기기와 공유되지 않습니다. 외부 소식은 `scripts/update-feeds.py`와 예약 워크플로가 갱신합니다.

GitHub Issues의 ‘개선 요청’ 또는 ‘오류 보고’를 사용하면 팀의 공통 작업 양식으로 기록할 수 있습니다. 작업자는 상태와 검증 결과를 남기고, 기능 변경 시 배포 결과를 확인합니다.
