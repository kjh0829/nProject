의상 검토실

새 옷을 등록하면 목록과 검사 조합에 자동으로 포함됩니다. 얼굴·목선·소매·허리·발목을 확대해 확인하는 개발용 화면입니다.

이 화면은 개인 착장과 지갑을 읽거나 저장하지 않습니다. 여기에 표시되는 옷은 검사용 조합입니다. 자동 접합 검사는 그림의 자연스러움이나 모든 문제의 부재를 보장하지 않습니다.

등록 규격 확인 중…

그림은 확대해서 확인해 주세요. 자동 검사 결과는 버튼을 누른 범위에만 해당합니다.

새 의상 추가 순서
  1. 카탈로그와 원화·좌표·피팅 프로필, 허리의 왼쪽·앞중심·오른쪽 기준점을 함께 등록합니다.
  2. 등록 규격 검사와 자동 조합 검사를 실행합니다.
  3. 이 화면에서 새 아이템을 선택하고 서로 맞닿는 조합을 확대 검토합니다.
  4. GitHub Actions의 검사 결과와 실패 좌표·확대 시트를 확인합니다.

자세한 등록·검사·실패 처리 규칙은 저장소의 team/briefs/AVATAR-QA.md에 있습니다. 이 페이지는 GitHub Actions 실행 결과를 자동 조회하거나 배포 승인을 표시하지 않습니다.
