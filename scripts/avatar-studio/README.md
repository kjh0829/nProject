# 3D 캐릭터 제작 시안

Blender 4.3의 EEVEE와 Pillow로 투명 렌더를 다시 출력할 수 있다. `--blend`를 지정하면 코디별 컬렉션과 재질 노드가 들어 있는 장면도 저장한다. `--draft`는 카메라와 소재를 빠르게 검토하는 저해상도 출력이다. 일부 착장만 다시 그릴 때는 `--outfit coat --outfit coat-beret`처럼 지정한다.

```bash
blender -b --python-exit-code 1 --python scripts/avatar-studio/render.py -- --output /tmp/alchankki-renders --blend /tmp/alchankki.blend
python scripts/avatar-studio/pack.py /tmp/alchankki-renders docs/assets/avatar-studio
```

`render.py`에서 고정 카메라·자세·조명으로 복숭아빛 피부와 라일락 웨이브·산책 데님을 출력한다. 상의 두 가지, 모자 유무, 신발 두 가지를 검토한다. 모자 밑에 눌린 머리와 옷 위로 내려오는 머리카락까지 함께 그리기 위해 윗부분은 상의와 모자의 네 조합으로 저장한다. 발 부분은 신발 두 종류를 공유한다. `pack.py`는 같은 데님의 중간 구간에서 두 이미지의 색과 알파를 맞춘 후 잘라낸다. 웹은 선택한 윗부분과 발 부분을 한 Canvas에 그린다. 6개 투명 WebP로 8개 착장을 만든다. 테스트 페이지는 `docs/avatar-3d.html`이다.

새 상의와 하의를 추가할 때는 렌더의 카메라·자세를 유지하고, 잘라내는 줄까지 옷이 내려오거나 다리 윤곽이 바뀌는지 먼저 본다. 이번 시안은 고정 데님에 맞춰 구간을 나눴다. 치마나 긴 코트로 확대할 때는 옷의 깊이와 가림이 바뀌는 부위의 레이어를 별도로 설계해야 한다.

얼굴은 원화의 3/4 윤곽을 따라 턱·광대·눈두덩·콧등의 깊이를 모델링했다. 기존 `faces.png`의 표정을 얼굴 표면에 UV로 맞추고 관자놀이와 뒷면에서 피부색에 섞는다. 편집용 Blender 파일에는 이 텍스처가 포함된다. 머리 가닥별로 폭과 두께, 색의 하이라이트를 정의하며 베레모 아래 앞머리는 눌린 형태를 사용한다. 소매 굴곡, 코트 자락, 데님 무릎, 베레모 리본과 부츠 굽은 실제 모델에 들어 있다.

맨머리의 정수리와 신발 밑바닥을 기준으로 원화의 키를 680×1060 렌더에 맞췄다. `fit_reference_pose`는 이 화면에서 잰 어깨·허리·골반과 팔다리의 위치를 3D 메시의 좌표에 적용한다. 머리·모발·모자는 함께 크기를 맞춘다. 팔은 손과 소매가 같은 변환을 따르고, 발은 좌우 발목을 중심으로 바짓단과 신발이 함께 회전한다. 비교 페이지의 전신과 확대 보기는 같은 배율을 쓴다. 브라우저 검사는 모자 없는 후디 착장에서 머리 주변의 폭, 골반 너비, 양쪽 발목 위치가 원화 기준에서 벗어나는 경우를 잡는다.

`cel_style.py`는 EEVEE 조명의 밝기를 세 단계로 나눠 바탕색에 입힌다. 얼굴은 UV 원화의 눈과 입이 잘 읽히도록 부드러운 명암을 쓰고, 금속 장식에는 좁은 반사광을 쓴다. 의상의 잔 요철을 줄이고 모델에서 만든 큰 주름을 색면으로 드러냈다. 화면 합성에서 어두운 자주색 외곽선을 2px 덧댄다. 각 재질의 `Wardrobe cel shading` 그룹에서 그림자와 하이라이트를 조정할 수 있다.

머리카락은 폭과 끝 위치가 서로 다른 얇은 메시를 겹쳐 만든다. 앞머리는 가르마에서 비스듬히 내려오고 베레모 아래 뿌리는 따로 눌러 두었다. 얼굴의 단면을 부드럽게 이었고, 턱 아래와 목에는 자연스럽게 이어지는 색을 넣었다.

`Wardrobe layered hair` 재질은 셀 명암, 뿌리와 골의 그림자, 반사광과 잔결을 순서대로 합성한다. `Lilac pigments`는 바탕색이다. `Hair paint masks`의 빨강은 그림자, 초록은 반사광 띠, 파랑은 잔결의 강도를 지정한다. `Hair stroke UV`는 가닥을 따라 잔결이 흐르게 한다. 각 레이어를 Blender 노드 그룹에서 조절하고 합성한 결과를 투명 이미지로 출력한다.

[2D 애니메이션풍 제작과 검사 기준](STYLE-GUIDE.md)에서 머리와 각 의상의 기준을 확인한다.
