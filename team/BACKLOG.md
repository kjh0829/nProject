# 개선 백로그

아래 표의 항목은 현재 ‘제안’ 상태다. 완료한 신규 작업은 하단에 별도로 기록한다. 실측 사용자 지표나 완료되지 않은 검증을 완료로 표시하지 않는다.

|---|---|---|---|---|
| T-01 | P1 | 모바일 핵심 흐름 점검 | 디자인·QA | 360/390px에서 4개 탭·입력·게임·게시판 가로 넘침과 터치/포커스 확인 |
| T-02 | P1 | 외부 읽을거리 품질 개선 | 콘텐츠·개발 | 게시일과 수집 시각 구분, 중복·관련성 기준, 빈 결과/오래된 정보 처리 |
| T-03 | P1 | 브라우저 저장 안내 개선 | 기획·디자인 | 목표·게임·게시판의 저장 위치와 삭제 영향을 필요한 위치에서 이해 가능 |

| T-06 | P2 | 재방문 가치 검증 | PM·기획 | 대표가 직접 1주 사용 후 자주 연 탭과 불편을 기록. 현재 분석 수집 없음 |

## 추천 다음 작업
식사 중심 전환에 따라 실제 한끼 기록 3~5개로 가격 기준·입력 부담을 먼저 검증한다. 이후 실사례 확보와 공유 DB·사진 저장소·운영 흐름을 설계한다. 기존 과제는 필요에 따라 진행한다.

## 신규 완료 작업
- T-09 · 매일 돌아오는 콘텐츠 흐름: 구현·배포 완료. 출퇴근 모드, 14일 순환 콘텐츠·퀴즈, 실천, 최근 7일 정원, 개인 한 줄 기록, 게임의 오늘 목표. [기획·구현·검증 기록](briefs/DAILY-RETURN.md).
- 360px/390px Chromium 핵심 흐름 자동 검증은 통과했다. T-01의 실제 휴대폰 터치·보조기술 확인과 T-06의 재방문 가치 검증은 후속으로 남긴다.

- T-10 · 재미 우선 첫 시안: 구현·배포 완료. 놀이터 홈, 목표 수집 퍼즐 5개, 특수 조각·얼음, 해답 검증된 날짜 도전, 진행 복원·공유, 창작 선택극 1화와 네 결말. [기획·검증 기록](briefs/PLAY-FIRST.md). 실제 재미·재방문 개선은 사용자 체험으로 후속 검증한다.
- T-11 · 재도전 흐름 개선: 구현·모바일 검증 완료. 스테이지별 저장과 기존 판 이관, 한 수 되돌리기, 목표 중심 힌트, 개인 별 기록, 발견한 결말 다시보기. [검토·구현·검증 기록](briefs/PLAY-REFINEMENT.md).
- T-12 · 재방문·모바일 탐색 개선: 구현·모바일 검증 완료. 탭/주소별 스크롤 복원, 뒤로 가기, 최근 7일 도전, 오늘의 개인 진행 표시, 16px 입력 글씨와 44px 퍼즐 조각. [검토·검증 기록](briefs/RETURN-USABILITY.md). 실제 iOS 키보드 동작은 후속 확인한다.
- T-13 · 판정·조작 복구: 구현·브라우저 검증 완료. 떨어진 특수 조각 때문에 새 번개가 사라지는 판정 오류, 재시작 취소와 저장 복원, 교환/무효 이동 피드백, 연쇄 후 키보드 포커스와 탭 이동 보호. [검토·검증 기록](briefs/PUZZLE-POLISH.md).

- T-14 · 식사 중심 전환: 구현·모바일/데스크톱 검증 완료. 알찬끼 홈, 재료·시간·비용 탐색, 투명한 인분 원가, 저장/먹어봄, 사진 포함 개인 기록·공유 텍스트. 실제 사용자 간 공유는 후속 DB 연결이 필요하다. [브레인스토밍·구현·검증](briefs/MEAL-PIVOT.md).

- T-15 · 혼자 쓰는 식탁 도구: 구현 및 360/390/1200px Chromium 자동 검증 완료. 재료 기반 메뉴 뽑기, 세 끼 준비 목록, 식사 일지·CSV. [범위·검증·운영 가설](briefs/SOLO-KITCHEN.md). 1주 실사용과 콘텐츠 다양성은 후속 검증한다.

- T-16 · 티커 기반 FIRE: 구현·배포 및 360/390/1200px Chromium 자동 검증 완료. 종목별 과거 CAGR, 평가액·월 투자액 복리, 물가 반영 목표, 가정 비교, CSV·저장 복원. 은퇴 후 인출·세금·환율 시나리오는 후속 범위다. [계산 기준과 검증](briefs/TICKER-FIRE.md).

- T-17 · 로그인 없는 티커 조회: 구현·배포, 실제 NVDA 외부 조회와 360/390/1200px 회귀 검증 완료. 종목명·참고 가격·통화·관측 CAGR, 수량/직접 환율로 개인 평가액 반영, 저장 복원·오래된 응답 방지. [조회 경로·개인정보 경계·검증](briefs/ANONYMOUS-TICKER.md). 공개 중계/Yahoo 인터페이스의 운영 안정성은 보장하지 않는다.

- T-18 · FIRE 간편화와 가상 한 달: 구현·배포, 360/390/1200px 전체 회귀 검증 완료. 기본 세 금액·즉시 결과·가정/종목 도구 접기, 생활비 전달·네 주 선택·예비비/적자·12개 개인 가상 기록. [설계·수용 기준·검증](briefs/SIMPLE-FIRE-LIFE.md). 실제 재미와 재방문은 사용 체험으로 후속 검증한다.

- T-19 · 월 예산별 생활비 기준표: 구현·배포, 360/390/1200px 회귀 검증 완료. 항목 입력을 제거하고 7개 비율/금액·하루 식비 예시를 자동 표시한다. 100원 단위 합계 일치, 예비비 계산, 기존 기록 보존 확인. 비율은 자체 예시이며 시세·권장 기준으로 표현하지 않는다.

- T-20 · 생활비 항목 ON/OFF: 구현·배포, 전체 128개 조합 단위 검증 및 360/390/1200px 회귀 검증 완료. 비례 재배분·제외 금액 0·비율/금액 합계, 전부 OFF/한 항목 복구, 설정 저장·복원 확인. [검증 실행](https://github.com/kjh0829/nProject/actions/runs/43561248981).
