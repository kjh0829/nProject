# 개선 백로그

모든 항목은 현재 ‘제안’ 상태다. 실측 사용자 지표나 완료되지 않은 검증을 완료로 표시하지 않는다.

| ID | 우선순위 | 과제 | 주 담당 | 완료 기준 |
|---|---|---|---|---|
| T-01 | P1 | 모바일 핵심 흐름 점검 | 디자인·QA | 360/390px에서 4개 탭·입력·게임·게시판 가로 넘침과 터치/포커스 확인 |
| T-02 | P1 | 외부 읽을거리 품질 개선 | 콘텐츠·개발 | 게시일과 수집 시각 구분, 중복·관련성 기준, 빈 결과/오래된 정보 처리 |
| T-03 | P1 | 브라우저 저장 안내 개선 | 기획·디자인 | 목표·게임·게시판의 저장 위치와 삭제 영향을 필요한 위치에서 이해 가능 |
| T-04 | P1 | 앱 파일 분리 | 개발·QA | CSS·게임·게시판·피드를 구분하고 기존 기능과 Pages 상대 경로 유지 |
| T-05 | P2 | 첫 방문 안내 | 기획·디자인 | 읽기·목표·놀이 중 시작 지점을 쉽게 선택, 반복 방문을 방해하지 않음 |
| T-06 | P2 | 재방문 가치 검증 | PM·기획 | 대표가 직접 1주 사용 후 자주 연 탭과 불편을 기록. 현재 분석 수집 없음 |

## 추천 첫 작업
T-01을 먼저 진행해 현재 모바일 사용성을 확인하고 발견된 문제만 고친다. 다음으로 T-02를 통해 ‘볼 만한 정보’의 품질을 높인다. 코드 분리는 여러 기능 수정에 부담이 생길 때 T-04로 진행한다.
