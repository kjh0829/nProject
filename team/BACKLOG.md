# 개선 백로그

아래 표의 항목은 현재 ‘제안’ 상태다. 완료한 신규 작업은 하단에 별도로 기록한다. 실측 사용자 지표나 완료되지 않은 검증을 완료로 표시하지 않는다.

| ID | 우선순위 | 과제 | 주 담당 | 완료 기준 |
|---|---|---|---|---|
| T-01 | P1 | 모바일 핵심 흐름 점검 | 디자인·QA | 360/390px에서 4개 탭·입력·게임·게시판 가로 넘침과 터치/포커스 확인 |
| T-02 | P1 | 외부 읽을거리 품질 개선 | 콘텐츠·개발 | 게시일과 수집 시각 구분, 중복·관련성 기준, 빈 결과/오래된 정보 처리 |
| T-03 | P1 | 브라우저 저장 안내 개선 | 기획·디자인 | 목표·게임·게시판의 저장 위치와 삭제 영향을 필요한 위치에서 이해 가능 |

## 추천 첫 작업
T-01을 먼저 진행해 현재 모바일 사용성을 확인하고 발견된 문제만 고친다. 다음으로 T-02를 통해 ‘볼 만한 정보’의 품질을 높인다. 코드 분리는 여러 기능 수정에 부담이 생길 때 T-04로 진행한다.

## 신규 완료 작업
- T-09 · 매일 돌아오는 콘텐츠 흐름: 구현·배포 완료. 출퇴근 모드, 14일 순환 콘텐츠·퀴즈, 실천, 최근 7일 정원, 개인 한 줄 기록, 게임의 오늘 목표. [기획·구현·검증 기록](briefs/DAILY-RETURN.md).
- 360px/390px Chromium 핵심 흐름 자동 검증은 통과했다. T-01의 실제 휴대폰 터치·보조기술 확인과 T-06의 재방문 가치 검증은 후속으로 남긴다.

- T-10 · 재미 우선 첫 시안: 구현·배포 완료. 놀이터 홈, 목표 수집 퍼즐 5개, 특수 조각·얼음, 해답 검증된 날짜 도전, 진행 복원·공유, 창작 선택극 1화와 네 결말. [기획·검증 기록](briefs/PLAY-FIRST.md). 실제 재미·재방문 개선은 사용자 체험으로 후속 검증한다.
