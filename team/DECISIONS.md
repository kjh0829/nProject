# 제품 결정 기록

## 2026-11-12 — 역할 기반 운영 시작
- 기획·디자인·개발·품질·콘텐츠/운영을 구분하고 총괄이 결과를 통합한다.
- 문서와 완료 기준으로 역할을 정의한다. 이 설정만으로 상시 에이전트가 실행되는 것은 아니다.
- 다중 에이전트 실행 여부는 사용자 의도에 따라 정한다.

## 현재 유지할 구현 결정
- 읽다·쌓다·쉬다·나누다를 주소 해시 기반 화면으로 제공한다.
- 목표·게임 최고 점수·체험 게시판은 브라우저 저장을 사용한다.
- 게시판에는 다른 사용자에게 공유되지 않는다는 안내를 유지한다.
- 외부 정보는 예약 RSS 수집 후 정적 JSON으로 제공한다.
- GitHub Pages는 개발·학습용으로 사용한다. 실제 상업 운영 시 호스팅을 재검토한다.
