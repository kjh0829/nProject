# 알찬끼의 작은 제품팀

적은 돈으로 알차게 먹는 한끼를 발견하고, 비용을 이해하고, 나의 식탁을 기록하는 모바일 웹서비스를 만든다.

## 의사결정과 역할
사용자는 대표이자 최종 제품 방향의 결정자다. Codex는 총괄 역할로 요구를 정리하고 필요한 역할을 수행하며 결과와 한계를 보고한다. 기본 운영은 한 에이전트의 역할 전환이다. 여러 AI 담당자의 실제 분담은 사용자가 요청할 때 시작하며 상시 실행되는 조직은 아니다.

| 파트 | 핵심 질문 | 산출물 |
|---|---|---|
| 총괄 / PM | 이번에 무엇을, 왜 만들까? | 범위·우선순위·담당 조정·결과 보고 |
| 기획 | 누구의 어떤 문제를 해결할까? | 사용자 흐름·수용 기준·성공 가설 |
| 디자인 | 휴대폰에서 이해하고 편하게 쓸 수 있나? | 화면 구조·상태·접근성 기준 |
| 개발 | 현재 환경에서 안정적으로 구현할 수 있나? | 코드·저장 구조·오류 처리 |
| 품질 / QA | 실제로 작동하며 기존 기능을 유지하나? | 시나리오별 결과·결함·검증 한계 |
| 콘텐츠 / 운영 | 매일 볼 이유가 있고 출처가 명확한가? | 수집 품질·문구·운영 상태 점검 |

역할별 세부 기준은 [ROLES.md](ROLES.md), 업무 흐름은 [WORKFLOW.md](WORKFLOW.md)를 참고한다.

## 현재 제품 상태
- 한끼 구경: 기획 예시 레시피 4개, 재료 검색, 비용·시간 필터, 비용/시간 정렬.
- 상세: 1인분 사용량 원가와 처음 포장 구매비 구분, 분량 조절, 조리법·팁.
- 내 식탁: 저장한끼·먹어본 한끼·내 기기 기록.
- 기록: 사진·재료비·조리법을 브라우저에 저장. 실제 이용자 간 공유는 아직 제공하지 않는다.
- 고르기: 재료·예산·시간 조건, 반복을 줄인 메뉴 뽑기, 세 끼 준비 계획·인분별 재료 목록.\n- 식사 일지: 날짜·끼니·원가 기준·만족도, 최근 7일 돌아보기, 수정·삭제·CSV 보관. 브라우저 전용이며 기기 간 동기화는 없다.\n- 주 메뉴는 구경·고르기·내 식탁·기록·더보기. 이전 퍼즐·이야기는 #arcade의 쉬는 틈으로 유지한다.
- 기존 금융 계산·개인 일기·체험 게시판과 저장 데이터도 유지한다.
- GitHub Pages의 학습용 정적 프로토타입이며 계정·공유 DB·실제 사용자 반응·행동 분석은 없다.

## 개선 방향
1. 대표가 실제 식사 3~5개를 기록해 원가 입력 부담과 저장 흐름을 확인한다.
2. 사용 허락이 확보된 실제 식사 사례로 예시 콘텐츠를 확장한다.
3. 공유 수요가 확인되면 인증·DB·사진 저장소·신고/삭제 기능을 함께 구현한다.
4. 상업 운영 전 호스팅과 개인정보·데이터 보존 방식을 결정한다.

기획 중인 개선은 [BACKLOG.md](BACKLOG.md), 결정 기록은 [DECISIONS.md](DECISIONS.md)에 남긴다. 업무 시작은 [briefs/TEMPLATE.md](briefs/TEMPLATE.md)를 필요한 만큼 작성하는 것으로 충분하다.

혼자 쓰는 재방문 흐름과 유지 비용 가설: [SOLO-KITCHEN.md](briefs/SOLO-KITCHEN.md). 실제 재미·지속 사용은 아직 검증되지 않았다.

- 주식 FIRE: 티커별 평가액·월 투자액, 최대 30년 관측 CAGR/직접 가정/개인 CSV, 개별 월 복리·물가 반영 목표·±3%p 비교·연도별 표. 기본 저장 자료 9개에 더해 로그인·API 키 없는 추가 티커 공개 조회를 제공한다. 참고 가격·통화·관측 CAGR, 선택 입력한 수량/직접 환율로 평가액을 반영한다. 다른 티커를 지수 수익률로 대체하지 않는다. [범위와 검증](briefs/TICKER-FIRE.md).

- [로그인 없는 종목 조회·개인 평가액 계산](briefs/ANONYMOUS-TICKER.md): 현재 원화·달러 주식/ETF 대상. 공개 중계 서비스 의존과 실패 시 대안을 UI에서 표시하며 계좌 잔고 자동 연결은 제공하지 않는다.

- FIRE 첫 화면은 자산·월 투자·목표 월 생활비 세 입력으로 단순화했다. 기존 티커 도구는 선택해서 펼친다. #fire-life는 예산별 네 주의 일상 선택과 최근 12개 가상 생활 기록을 제공한다. 창작 비용 가정이며 실제 시세/생활 수준 평가는 아니다. [간편화·가상 한 달·검증](briefs/SIMPLE-FIRE-LIFE.md).

- 가상 한 달은 월 예산만 입력하면 7개 항목의 금액·비율이 나오는 생활비 기준표로 개선했다. 월 200만 원 예시는 월세60/식비40/생활 필수20/교통10/여가20/예비20/여유30만 원이다. 자체 배분 예시이며 공식 권장 기준이나 실제 매물 가격이 아니다. 과거 수동 입력 기록은 그대로 보존한다.

- 생활비 항목별 ON/OFF를 제공한다. 집을 보유했다면 월세를 제외하는 식으로 사용할 수 있고, 나머지 켜진 항목은 기본 가중치 비례로 자동 재배분한다. 모든 항목 OFF는 전액 미배분 상태로 보관한다. 기존 기록은 변경하지 않는다.
