# 알찬끼의 작은 제품팀

3매치 퍼즐과 여행, 포인트로 모은 의상으로 나만의 2D 캐릭터를 꾸미는 모바일 웹서비스를 만든다.

## 현재 사용 흐름
| 메뉴 | 하는 일 |
|---|---|
| 홈 | 스테이지 또는 랜덤 한 판 선택 → 내 캐릭터 → 첫 클리어 보상 |
| 게임 | 스테이지·랜덤 한 판을 같은 비중으로 선택, 전체 지도·접힌 날짜별/연습 판과 기믹 도전 |
| 꾸미기 | 내 캐릭터·상점·옷장, 접힌 초기 디자인 원화 참고 |
| 내 기록 | 스테이지 진행·별·보유 의상/포인트, 접힌 생활 도구 |


이전 기록 보관함은 사용자 요청으로 제거했다. 예전 읽기/퀴즈/일기와 실험 기능의 메뉴는 제공하지 않으며, 기존 브라우저 저장 데이터는 삭제하지 않는다. 식사·자유 매치·게시판의 기존 직접 주소는 유지한다. [전체 재검토와 구현·검증 기록](briefs/SITE-REVIEW.md).

## 현재 제약
- GitHub Pages 학습용 정적 프로토타입이다. 개인 기록은 이 브라우저에만 보관하며 계정·기기 간 동기화·공유 DB는 없다.
- 식사 예시 4개는 가정 단가와 AI 이미지다. 실제 사용자 글/시세로 표현하지 않는다. 사진 포함 개인 레시피는 별도로 저장한다.
- 식사 일지 CSV는 사진·레시피·FIRE 계획 전체 백업이 아니다. 브라우저 데이터 삭제 영향은 기록 탭에서 안내한다.
- FIRE 수익률과 생활비 비율은 가정/예시다. 수익이나 실제 주거 가능성을 보장하지 않는다. 주가 조회는 공개 중계 서비스에 의존하며 평가액·생활비를 외부로 보내지 않는다.
- 행동 분석·실제 트래픽/수익 측정은 도입하지 않았다. 재미와 재방문은 실사용으로 확인할 가설이다.

## 다음 우선순위
1. 지역 배경·장식·배지 수집과 찜한 의상을 목표로 하는 플레이 흐름을 실사용으로 확인.
2. 포인트·구매·착장·여행 진행의 백업·복원은 사용자 요청으로 보류.
3. 새 스테이지 난이도/다양성과 꾸미기 만족도를 일주일 실사용으로 확인.
4. 기존 코드 분리, 데이터 수집 안정화, 상업 운영 전 호스팅 검토.

## 운영 방식
사용자는 제품 방향의 결정자다. 기본적으로 한 에이전트가 기획·디자인·개발·QA 역할을 차례로 수행한다. 여러 담당자의 병렬 작업은 사용자가 요청할 때 시작하며 상시 직원 조직은 아니다. 책임은 [ROLES.md](ROLES.md), 절차는 [WORKFLOW.md](WORKFLOW.md), 과제는 [BACKLOG.md](BACKLOG.md)를 따른다.

[소프트 아케이드 디자인](briefs/SOFT-ARCADE.md): 장보기 조합 계산은 홈/기록에서 열며 기존 주소와 데이터는 유지한다. 글 자동 발행은 사용자 요청으로 일시 중지 상태다.

선택극은 사용자 요청으로 홈/게임/퍼즐의 진입점에서 제외했다. 과거 링크와 개인 결말 기록은 호환을 위해 보존하며 게임 탭에서 이야기 기록을 조회하지 않는다.

- [20수 점수 모드](briefs/TWENTY-MOVES.md): `#challenge?mode=score`, 별도 브라우저 저장, 시간 제한 없이 20번의 유효 교환으로 개인 최고 점수에 도전한다.

- [특수 조각과 조합](briefs/SPECIAL-COMBOS.md): 가로·세로 번개/주변 폭탄/무지개 구슬 및 모든 특수 계열 교환 조합. 게임 도움말과 조각 선택 설명에서 규칙을 확인할 수 있다.

- [특수 기믹 도전](briefs/MECHANICS-LAB.md): `#lab`에서 로켓·연결 폭탄·회오리·성장 폭탄, 충전 스킬, 상자/사슬/포털/컨베이어와 종료 보너스를 즐긴다. 기존 모드와 진행/최고 기록은 별도다.

- [집중 모드·별빛 배달 여행](briefs/JOURNEY-FOCUS.md): 게임 집중/선택형 전체화면, #journey의 3지역·15판 순차 해금과 별 기록. 예전 선택극과 구분되는 퍼즐 스토리이며 기록은 별도 브라우저 키에 보관한다.

- [확장형 여행 지도](briefs/JOURNEY-MAP.md): 선택한 지역/구간만 표시하고 실제 진행 이어하기를 분리한다. 콘텐츠는 지역 pack을 뒤에 추가하며 총량/해금/지역 결말을 자동 계산한다. 현재 실제 콘텐츠는 4지역·20판이다.

- [내 캐릭터·상점·옷장](briefs/AVATAR-WARDROBE.md): #avatar에서 직접 만든 2D 캐릭터의 6부위/52아이템을 미리보기·구매·착용한다. 첫 선물 100P와 게임 완료 보상, 같은 판 중복 지급 방지. 포인트와 착장은 이 브라우저에만 저장하는 게임 재화이며 실제 금전 거래는 없다.

- [게임 중심 정리·개선 제안](briefs/GAME-FOCUS-REVIEW.md): 홈/주요 기록에서 식사 콘텐츠를 제외하고 기존 데이터는 보관함에서 유지한다. 지역 보상/착장 프리셋/게임 품질/백업/이름과 메뉴 정리는 후속 제안이며 이번에 구현한 기능으로 표현하지 않는다.

- [B안 셀 채색 아바타](briefs/AVATAR-CEL-B.md): 약 6등신 전신과 기존 22개 의상을 공통 관절/레이어로 교체했다. 숨쉬기·눈 깜빡임·인사·승리, 부위별 상점 확대와 전신 확대 보기. 포인트·소유권·착장은 그대로 유지한다.

- [정지원화 품질 우선](briefs/AVATAR-QUALITY-MASTER.md): B 기준 원화 레이어로 22개 의상·피부·표정을 실제 코디한다. #avatar가 기본 코디/상점/옷장이며 초기 고정 원화는 #avatar?view=reference다. 포즈 실험은 중단 상태, 기존 지갑/구매 기록은 그대로 유지한다.

- [확장형 의상 검사](briefs/AVATAR-QA.md): 필수 피팅 프로필과 원화 registry, 카탈로그에서 생성하는 접합 조합, CI 분할/누락 집계, 개발용 `avatar-review/` 확대 검토실. 현재 52개 아이템/776개 중복 제거 검사 사례이며 새 아이템이 자동 포함된다. 자동 검사와 육안 검토를 함께 사용한다.

- [테마 컬렉션 5종](briefs/AVATAR-FIVE-THEMES.md): 벚꽃·바다·별빛 도서관·숲·겨울 카페, 부위별5개/총30개 추가와 테마 필터. 전체52개, 기존 포인트와 구매 기록 유지.

- [전신 피팅 검토](briefs/AVATAR-FULL-FIT.md): 52개 아이템의 머리/허리/발목/소품 조합을 확대 비교하고 가방·안경·바짓단·부츠·피부색 필터를 보정했다. 자동 검사는 776개 고유 사례로 확장했다.

- [4개 메뉴 정리](briefs/MENU-FOCUS.md): 게임과 코디를 주 흐름으로, 생활 도구·예전 콘텐츠는 내 기록에서 보조 메뉴로 제공한다.

- 의상 목표·코디 저장: 의상 찜을 홈/게임 결과에 표시하고 여러 부위 구매·착용을 한 번에 저장한다. 보유 의상 코디 3개를 이름으로 저장·불러오며 홈에 전신 코디를 진열한다. 세 지역 완주로 배경·기념 장식·배지를 해금한다. 모두 현재 브라우저에 저장되며 백업·복원 기능은 사용자 요청으로 보류한다.

- 플레이 개선: 실제 터치 드래그, 첫 교환/처음 만난 특수 조각 안내, 프리즘 공방 16~20번 미션판, 최고 기록 추격과 최근10판 점수 그래프, 의상 검색/구매 가능/미보유/가격·이름순 정렬, 900×1200 PNG 코디 카드 저장을 제공한다. 대표 이름은 알찬끼, 여행 게임 이름은 별빛 배달 여행이다.

- [목표 피드백·재도전](briefs/GOAL-FEEDBACK.md): 수집/얼음/특수 미션 달성 표시, 남은 3수 안내, 결과창의 실제 부족분과 마지막 한 수 복원, 미션에 맞는 힌트. 점수·판정·저장 형식은 유지한다.

- 홈/게임의 플레이 선택은 `스테이지`(목표 클리어·순차 진행)와 `랜덤 한 판`(매번 다른 배치·20번 교환)을 같은 이름/순서로 나란히 표시한다. 진행 중인 랜덤 판은 이어가고, 완료한 뒤에는 홈/게임에서 새 랜덤 판을 바로 연다.

- [상·하의 허리 피팅](briefs/AVATAR-WAIST-FIT.md): 돌아선 자세의 L/F/R 허리 기준점, 상의·하의의 중심/기울기 보정, 기존 관절 고정, 작은 화면 분할선 정리. 새 의상에도 필수 등록과 실제 렌더 기준점 검사를 적용한다. QA는 wardrobe-qa-v2, 776개 사례/13분할이다.
