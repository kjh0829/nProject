# 알찬끼 작업 기억

사용자가 다음 작업에도 이어가길 원하는 제품 방향과 반복해서 짚은 품질 기준을 모은다. 기준이 바뀌면 해당 항목을 최신 요청으로 고치고, 보류한 작업은 사용자가 재개할 때 상태를 바꾼다. 채팅 원문과 개인 기록을 옮기지 않고 작업에 필요한 결정만 적는다.

## 캐릭터와 옷장

| 적용 범위 | 이어갈 요청 | 작업 후 확인 |
| --- | --- | --- |
| 3D 제작 시안의 체형 | 같은 배율의 옷장 원화를 기준으로 한다. 어깨는 좁고 자연스럽게 기울며, 가슴이 앞으로 과하게 돌출되지 않고 몸판이 얕고 둥글게 돌아 허리·골반으로 이어지는 실루엣을 선호한다. | 후디와 코트 각각에서 어깨 폭, 가슴의 가장 바깥쪽과 그 위아래 곡률, 허리선과 골반 양옆을 본다. 원화보다 앞선의 돌출을 조금 줄이고, 후디 끈·코트 깃과 가까운 쪽 옷감의 그늘까지 전신과 확대에서 비교한다. 어깨를 줄이는 작업에서도 몸통의 입체감을 따로 확인한다. |
| 얼굴과 헤어 | 정지 상태의 2D 애니메이션풍 인상이 우선이다. 원화처럼 앞머리가 한쪽 눈썹을 스치고, 옆머리는 귀를 감싸 어깨로 떨어진다. 정수리와 볼 옆의 부피, 목 굵기도 원화와 맞춘다. | 전신과 헤어 확대에서 눈매, 귀 옆의 틈, 가닥의 겹침과 반사광을 확인한다. |
| 3D 시안의 모자 | 일반 헤어와 모자 쓴 헤어를 각각 한 스타일로 만든다. | 베레모를 골랐을 때 전용 앞머리가 챙 아래에 앉는지 본다. |
| 새 의상과 피팅 | 코디가 늘어나도 목·카라·손목, 상하의 허리선, 신발 입구가 몸의 각도를 따른다. 포즈보다 가만히 서 있는 착장의 완성도를 먼저 맞춘다. | 실제 착장으로 접점을 확대한다. 시안의 후디 끈과 코트 깃은 앞판 곡면을 따라가야 한다. |
| 게임 속 옷장 | 플레이로 모은 포인트로 옷을 사고, 가진 옷으로 캐릭터를 꾸민다. | 구매·착용·재접속을 거쳐 보유 의상과 착장이 이어지는지 확인한다. |

3D 시안은 Blender에서 착장을 렌더해 웹에 이미지로 제공한다. 게임 옷장의 모바일 렌더링과 구매 데이터에는 별도 기준이 있다. [시안 제작 기준](../scripts/avatar-studio/STYLE-GUIDE.md) · [의상 검사](briefs/AVATAR-QA.md) · [모바일 옷장](briefs/AVATAR-IOS-CANVAS.md)

## 게임과 사이트

- 홈과 게임에서 스테이지와 반복 가능한 랜덤 한 판을 모두 쉽게 찾게 한다. 스테이지를 늘려도 지도가 복잡해지지 않아야 한다. 게임 설명을 위한 이야기와 이전 기록 보관함은 제거한 상태다.
- 3매치에서는 한 번의 성공이 연쇄로 이어지는 타격감과 직관적인 효과를 우선한다. 휴대폰에서 집중 모드로 플레이할 수 있어야 하며, 조각을 연달아 눌러도 화면 배율이 바뀌지 않아야 한다.
- DB가 필요한 사용자 간 공유는 보류 중이다. 매시간 FIRE 글을 발행하는 실험도 사용자 요청으로 일시 중지했다. 두 작업의 재개 여부는 다음 관련 요청에서 확인한다.

## 생활 도구

- FIRE 계산기는 현재 자산을 입력한 뒤 목표 달성까지 간단히 확인하는 흐름을 우선한다. 종목별 보유 자산과 수익률 가정을 쓰는 계산은 상세 도구에서 제공한다.
- 가상 한 달 살기는 월 예산을 입력하면 주거비와 식비 등의 기준 금액을 제시한다. 사용자가 지출 항목을 끄면 나머지 항목에 비례 배분한다.

현재 메뉴와 기능별 구현 기록은 [팀의 제품 현황](README.md), [전체 재검토 기록](briefs/GAME-FOCUS-REVIEW.md)에 있다.
