# 로그인 없는 티커 조회

## 목표와 선택
GitHub Pages와 브라우저 개인 기록 구조를 유지하면서 티커 등록 뒤 공개 종목 정보를 조회한다. 증권사 계정 연결·API 키·사용자 로그인을 요구하지 않는다. 개인 보유 수량/매입가/계좌 잔고는 공개 정보로 알 수 없으므로 직접 입력한다.

기존 Yahoo 공개 가격 조회를 브라우저에서 직접 호출하면 CORS로 읽지 못했다. 실제 Chromium에서 direct 실패, cors.dev 경유 성공, AllOrigins 실패를 확인했다. 실제로 성공한 cors.dev 경로 하나만 사용한다. 사이트 이전·별도 서버 계정 생성·임의 프록시 순환은 하지 않는다. 공개 중계의 지속 제공이나 Yahoo 비공식 인터페이스의 안정성은 보장되지 않으며 실패 시 기존 근거/직접 가정/CSV를 유지한다.

## 동작
- 티커 정리: 소문자를 대문자로, 국내 6자리 코드를 .KS로 정리한다. 코스닥은 .KQ를 직접 지정한다. 이름 검색은 제공하지 않는다.
- ‘종목 정보 조회’에서 종목명·통화·참고 가격/기준 시각·최대 30년 조정주가 CAGR을 가져온다. 현재 원화/달러 주식·ETF 대상이며 지수/선물/환율은 자동 종목 조회 대상이 아니다.
- 요청 주소는 고정 Yahoo chart 호스트와 검증한 티커·기간 파라미터로만 구성한다. credentials omit, no-referrer. 사용자 수량·평가액·환율·생활비는 전송하지 않는다. UI에서 조회 경로와 비공식 서비스 의존을 표시한다.
- 종목 일치·통화·양수 가격·유효 시각·조정주가 형식·기간·계산 범위를 검사한다. 배당 조정 열이 없거나 관측 자료가 1년 미만이면 CAGR을 만들지 않는다. 시작/끝 관측값·기간·출처를 표시한다.
- 선택 입력한 수량×참고 가격×직접 환율÷10,000으로 원화 만 원 평가액을 계산한다. 원화 종목은 환율 1이며 사용자가 ‘평가액 반영’을 누를 때만 평가액을 바꾼다. 참고 가격은 실시간 체결가로 보장하지 않는다.
- 티커 변경·삭제 후 늦게 도착한 이전 응답은 적용하지 않는다. 같은 티커 동시 요청은 합치고 공개 조회 결과는 메모리에 최대 30개/24시간 보관한다. 다시 조회하면 갱신한다. 자동 반복 호출은 하지 않는다.
- 계산·저장 버튼은 적용 근거와 참고 가격·선택한 수량/환율을 기존 개인 포트폴리오 키에 함께 보관한다. 원본 일별 가격 배열은 저장하지 않는다. 이전 포트폴리오 데이터도 읽을 수 있다.

## GitHub Actions의 역할
저장소의 지정 작업을 GitHub 서버에서 자동 실행하는 기능이다. 이 프로젝트에서는 공개 자료 정기 수집·테스트·배포 검증에 사용한다. 사용자가 누르는 종목 조회는 브라우저에서 즉시 진행하므로 Actions 실행을 기다리지 않는다. 학습용 정적 구조를 유지하는 기능이며 증권사 계좌 연동이 아니다.
