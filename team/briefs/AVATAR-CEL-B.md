# B안 적용: 셀 채색 캐릭터와 공통 관절

## 디자인
사용자가 선택한 B 방향을 실제 꾸미기 화면에 적용했다. 기존 블록형 그림을 약 6등신의 선화·셀 채색 SVG로 교체했다. 전신 300×540 좌표, 피부·얼굴·머리·의상의 명암 면과 선을 직접 작성했다. 컨셉 이미지를 평면으로 붙이는 방식이 아니라 실제 22개 아이템을 계속 갈아입힐 수 있는 레이어 원화다. 기존 아이템 ID/이름/색/가격과 구매·포인트 저장 형식은 유지한다.

상의 4종, 머리 4종, 모자 3종, 하의 4종, 신발 4종, 소품 3종을 새 비율에 맞췄다. 코트는 멜빵 앞판보다 바깥에 있는 옷이므로 코트 착용 시 멜빵 앞판은 숨기고 바지는 유지한다. 안경은 얼굴, 모자는 머리, 가방은 몸통, 새 친구는 어깨 옆 기준에 붙는다.

## 움직임과 레이어 구조
- avatar-rig.mjs의 cel-b-v1 공통 좌표/머리·몸통·어깨·팔꿈치·머리끈 기준점을 사용한다. SVG에 같은 기준점을 CSS 변수로 출력해 avatar-cel.css의 회전 중심과 공유한다.
- 팔은 어깨→팔꿈치→손의 중첩 그룹이다. 소매는 해당 팔의 그룹 안에서 피부/손과 함께 움직인다. 모든 옷에 각각의 애니메이션을 복사하지 않는다. 긴 소매의 팔꿈치에는 같은 색 연결 면을 둔다.
- 기본 숨쉬기·눈 깜빡임, 인사·승리 미리보기. 포즈 선택은 UI 상태이며 포인트/구매/착장에는 쓰지 않는다. 눈·팔·머리의 CSS 키프레임만 움직이고 상점 썸네일은 정지 상태다.
- 동작 줄이기에서는 모든 캐릭터 애니메이션을 끄고 인사/승리는 정지 자세로 보여준다.
- 옷의 종류가 크게 달라지거나 걷기 등 다른 전신 동작을 추가할 때에는 새 옷의 관절 분할과 가림 범위를 검토해야 한다. 이번 구조가 모든 미래 의상·동작을 자동 생성한다는 의미는 아니다.

## 꾸미기 화면
상점 썸네일은 머리/모자/상의/하의/신발/소품별로 해당 부위를 확대한다. 프로필과 게임 결과의 작은 아바타는 상반신을 보여준다. 메인 캐릭터는 전신이며 ‘확대’ 대화상자에서 세부를 볼 수 있다. 대화상자는 닫기/Escape/다른 탭 이동으로 닫힌다.

모바일에서 스크롤 중에는 작은 미리보기로 줄여 상점·구매 버튼을 가리지 않는다. 피부/표정 상세를 열면 고정을 풀어 편집할 수 있다. 확대 보기와 포즈는 구매나 미리보기 의상 저장으로 간주하지 않는다. 기존 옷장·포인트·게임 규칙은 바꾸지 않는다.

## 아이템 추가 규칙
1. 기존 avatar-data.mjs ID/가격은 보존하고 새 아이템을 추가한다. 같은 형태의 새 색상은 기존 style을 재사용할 수 있다.
2. 새 형태는 avatar-art.mjs의 부위별 빌더에 추가한다. 팔이 있는 옷은 어깨/팔꿈치 그룹을 사용한다. 몸통 그림에 손/팔을 통째로 넣지 않는다.
3. 긴 옷/원피스처럼 다른 부위를 덮는 옷은 avatarCoverage 가림 규칙부터 정의한다. 모자와 안경은 머리 그룹 안에 넣는다.
4. 부위 확대 영역은 avatarFraming에서 정한다. 새 형태를 전신·확대·썸네일, 기본/인사/승리, 피부 4종에서 확인한다.
5. 리그 기준점을 바꾸면 호환되는 모든 의상과 포즈를 다시 검증하고 새 버전을 고려한다. 자산/인벤토리 이관은 이번 작업에 없다.

## 검증
avatar-cel.test.mjs: 모든 공개 아이템의 부위 확대, 네 코디×세 포즈, 관절/레이어 계약, 코트/멜빵 가림, SVG 안전성과 기존 지갑을 변경하지 않는 렌더링.
avatar-cel-browser.cjs: 320/390/1200px, 세 코디와 정지 포즈, 소매/손의 관절 소속, 확대/Escape/작은 화면 배치, 구매 영역의 축소 미리보기, CSS 애니메이션 시간 샘플에서 실제 팔 회전과 눈 깜빡임 확인. 기존 avatar-browser의 구매/착용/벗기/잔액/중복 보상/저장 실패 흐름도 유지한다.

실제 기기의 체감 부드러움과 그림체 만족도는 사용자 체험으로 확인한다. 이 결과를 컨셉 일러스트와 동일한 원화 품질이나 새 방문/수익 성과로 표현하지 않는다.
