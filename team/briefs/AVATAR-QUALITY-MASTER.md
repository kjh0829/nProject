# 정지 원화 품질 우선 — 기본 코디 1벌

## 문제와 이번 범위
선택된 B 컨셉은 섬세한 캐릭터 일러스트였지만 실제 적용은 단순한 SVG 도형에 머물러 품질 차이가 컸다. 기능 검사와 원화 품질을 동일시한 판단을 수정한다. 사용자는 움직임보다 가만히 있는 모습의 품질을 먼저 확보하도록 지시했다.

기본 캐릭터와 코디 한 벌을 B 원화 기준으로 새로 제작하고, 해당 이미지를 웹에서 그대로 표시한다. 얼굴·머릿결·손·의상 소재/주름/금속 장식의 디테일을 유지한다. 원화를 다시 SVG 윤곽으로 축약하거나 단순한 관절 그림으로 바꾸지 않는다. 인사·승리·숨쉬기 등 기존 SVG 동작 실험은 화면에서 중단했다.

## 실제 적용과 구분
- #avatar 기본 화면: ‘새 캐릭터 원화’. 라일락 여행자의 전신 정지 원화, 같은 이미지의 얼굴 확대, 원본 확대 대화상자를 제공한다.
- #avatar?view=wardrobe: ‘내 옷장 · 기존 착장’. 기존 22개 아이템의 구매/미리보기/착용과 지갑을 그대로 사용할 수 있다. 이 호환 화면은 기존 SVG 렌더러를 사용하며, 새로운 원화 품질로 변환됐다고 표현하지 않는다.
- 새 원화는 **기본 코디 한 벌의 품질 기준**이다. 보유 옷/피부/표정/소품을 새 원화에 조합하는 기능은 아직 구현하지 않았다. 이 구분을 실제 페이지에 표시하고 새 원화에 포인트나 개별 아이템 소유권을 연결하지 않는다.
- 게임 보상 링크는 기존 옷장으로 직접 연결해 구매 흐름을 보존한다. 포인트/구매/착장/게임 기록의 키와 데이터 형식은 바꾸지 않는다.

## 원화 자산
- assets/avatar-art/lilac-traveler-v1.png, 1024×1536 RGBA, 약 1.5 MB.
- 사용자 선택 B 컨셉을 참조해 image_gen으로 제작한 오리지널 성인 캐릭터 일러스트. 기존 게임 캐릭터/스프라이트를 가져오지 않는다.
- 생성 결과 PNG를 편집/재도형화/재인코딩하지 않고 그대로 복사해 배포한다. Git blob SHA: 9e976579b5e6bbb7d90d3c9161fdd12003557a29. alpha가 있는 그림이며 단색 배경을 이미지에 합성하지 않는다.
- 동일한 이미지 소스를 전신/얼굴 확대/확대 대화상자에 사용한다. CSS의 contain/확대 프레임만 다르고 얼굴을 따로 재생성하지 않는다. img의 lazy loading과 브라우저 캐시를 사용하며 사용자 기기에서 이미지 생성 API를 호출하지 않는다.
- avatar-quality.mjs/avatar-quality.css는 원화 표시와 화면 구분만 담당하고 지갑 저장 함수를 호출하지 않는다.

## 이후 의상 확장의 품질 기준
먼저 이 정지원화 수준과 캐릭터 정체성을 유지한다. 몸체/얼굴/머리/의상 자산을 분리할 때에는 동일 캔버스·동일 자세·동일 신체 비율을 기준으로 제작하고, 다시 합친 결과를 원화와 나란히 확인한다. 얼굴과 옷을 기존 SVG로 대체해 기능만 성립시킨 결과를 새 그래픽 적용으로 보고하지 않는다. 실제로 품질과 정렬이 확인된 부위만 새 렌더러에 연결하고 그때까지 원화 보기와 기존 옷장을 구분한다. 새로운 포즈/걷기 등은 이 단계보다 뒤다.

## 검증
- 실제 전신/얼굴 확대 화면을 B 기준 이미지와 육안 비교했다. 모바일·데스크톱 스크린샷에서 같은 PNG가 원화 품질 그대로 표시되는지 확인했다. 이 육안 비교를 자동 검사나 사용자 만족도 측정으로 표현하지 않는다.
- avatar-quality-browser: 320/390/1200px 원화 1024px 로드, 동일 소스, 전신 contain, 정지 상태, 기본 코디/보유 착장 구분, 모달/Escape/모드·뒤로가기, 이전 지갑 byte 보존, 가로 넘침.
- 기존 avatar-browser는 보관된 실제 옷장 경로로 진입하며 구매/차감/착용/보상/동시 탭/손상 데이터 보존을 그대로 검사한다.
- avatar-cel-browser는 호환 렌더러의 레이어/확대/저장 호환성과 정지 상태를 확인한다. 동작 재생을 요구하던 검사는 사용자 지시에 맞춰 중단한 실험의 수용 기준에서 제외한다.
