# 상·하의 허리 각도와 작은 화면의 합성 경계

2026-11-21. 사용자 지적에 따라 상의 9종 × 하의 9종의 허리와 전신을 확대 비교했다. PNG 원본, 아이템 52개의 ID/가격, 구매·착장·포인트 데이터는 유지한다.

## 확인한 문제
- 상의는 목/소매를 고정 자세에 맞췄지만 하의는 사각형 확대와 허리 위쪽 42px 늘리기에 의존했다. 따라서 연결이 불투명해도 허리 폭, 앞중심, 기울기 차이는 검사에서 통과할 수 있었다. 이전 `waist-connection`은 이 빈틈만 확인하는 검사였다.
- 실제 렌더의 원단 안에 가는 수평/분할선이 있었다. 원본의 작은 잔여 배경 알파와, 0.8px짜리 삼각형 겹침이 축소된 옷장 화면에서 충분하지 않은 점을 확인했다. 긴 바지의 종아리 분할도 같은 문제를 만들 수 있었다.

## 보정
- `avatar-waist.mjs`의 공통 자세 좌표는 왼쪽 (425,620), 앞중심 (568,648), 오른쪽 (668,632)다. 사각형 중앙이나 수평선 대신 이 세 점으로 몸의 돌아선 방향을 표현한다. 공통 렌더 기준이며 별도의 3D 측정값은 아니다.
- 모든 상·하의의 `waist.points`는 기존 source→target 배치 좌표에서 지정한 왼쪽·앞중심·오른쪽 기준점이다. `rise`는 허리 높이 차이다. 현재 멜빵은 -40, 나머지는 0이며 멜빵의 높은 허리는 유지한다.
- 상의는 기존 목/손목 망과 같은 꼭짓점에서 허리만 맞춘다. 소매의 선택 기준을 망의 열 번호에서 실제 좌표로 바꿔, 허리 열을 추가해도 손목이 움직이지 않게 했다. 목·손목 밖의 관절을 옷 전체와 함께 회전시키지 않는다.
- 하의는 같은 기준면에 허리·골반을 맞추고, 900(높은 허리는 950) 아래에서 보정을 끝낸다. 무릎·발목과 기존 밑단 보정은 유지한다. 예전 42px 늘리기/고정 join은 제거했다.
- `avatar-mesh.mjs`의 공유 삼각형은 3px씩 겹치게 했다. 원단 전용 렌더 필터가 미세 잔여 배경 알파를 제거하고 불투명 원단의 알파를 정리한다. 피부/머리/원본 PNG에는 적용하지 않는다. 바지 분할은 source/target을 함께 연장해 겹치므로 천을 다시 늘리지 않는다.

## 새 의상을 등록할 때
1. 정지 원화와 같은 몸체·돌아선 자세로 제작한다. 정면/다른 포즈의 옷을 사각형으로 맞춰 등록하지 않는다. 프레임이 다른 디자인은 별도 피팅 프로필과 확대 검토가 필요하다.
2. atlas/source/target/profile과 함께 `waist: {points:[[x,y],[x,y],[x,y]],rise:0}`을 등록한다. 좌표는 **목/소매/허리 보정 전, target에 놓인 원화의 좌표**다. 그림의 허리 선과 앞중심을 보고 정하며 target 사각형 중앙으로 자동 생성하지 않는다.
3. 새 상/하의는 기준점 누락·부위 오류·잘못된 순서·비정상 높이·망 접힘이 있으면 등록 검사에서 실패한다. 이전 아이템을 복사한 좌표가 그림에도 맞는지 육안 확인한다.
4. 카탈로그에서 상의×하의 조합이 자동 생성된다. 검토실에서 새 아이템을 골라 ‘골반·하의 각도’와 전신을 확인한다. 좌표 가이드를 켜면 L/F/R 기준선을 볼 수 있고, 끄면 실제 그림만 볼 수 있다.
5. 원단의 겹침 깊이, 옷의 입체감, 목/손목/발목·소품과의 조합은 자동 통과만으로 보장하지 않는다. 고정 포즈에 맞춘 2D 합성이며 새 포즈나 모든 실루엣을 자동 재제작하는 기능은 아니다.

## 검증
- 등록/단위: 모든 상·하의 기준점과 비정상 등록 거부, 각 기준점이 공통 좌표에 맞는지, 목/손/무릎/발목을 움직이지 않는지 확인한다. 새 의상의 관련 조합 자동 포함은 기존 검사로 유지한다.
- 실제 픽셀: 상의×하의와 상·하의 단독 검사의 원화 소스에 임시 표식을 넣어 실제 렌더된 세 점의 위치를 확인한다. 멜빵 안으로 들어간 상의는 이 기하 검사에서만 tucked clip을 해제한다. 실제 착장의 겹침과 빈틈은 원래 합성 픽셀로 별도 검사한다. 잘못된 렌더 변환을 제거한 fixture가 실패하는지 확인한다.
- 작은 화면: 176px 렌더의 단색 원단으로 분할선의 알파를 읽고, 과거 0.8px 겹침 fixture와 구분한다. 기존 목/손목/머리/부츠/피부색 회귀도 유지한다.
- `wardrobe-qa-v2`: 카탈로그 52개/776개 고유 사례/13분할을 모두 검사하고 집계한다. 일부 분할 통과와 전체 통과, Pages 배포 결과를 구분한다.
- 실제 옷장/확대/상점/코디 PNG는 같은 합성기를 사용한다. 모바일 흐름과 PNG 생성도 확인한다. 외부 전송이나 개인 데이터 변경은 추가하지 않는다.
