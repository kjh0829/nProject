# 게임으로 꾸미는 2D 캐릭터

## 제품 경험
#avatar는 게임 탭에 속하며 상점/내 옷장, 부위 선택, 실제 착장과 구분한 구매 전 미리보기, 구매 후 착용, 모자/소품 벗기를 제공한다. 피부 4종과 표정 3종은 무료다. 기본 착장 포함 22개 아이템이며 머리·모자·상의·하의·신발·소품 6부위를 조합한다. 모바일에서는 옷을 둘러보는 동안 미리보기를 상단에 유지한다. 기본 모습 상세를 열면 패널 고정을 풀어 작은 화면에서도 편집할 수 있다.

아트는 avatar-art.mjs에서 직접 만든 2D 도형 레이어로 렌더링한다. 타 게임의 캐릭터·옷·스프라이트를 가져오지 않았다. 실제 착장과 피부·표정은 저장하며, 미구매 미리보기는 저장하지 않는다. 동작 줄이기에서는 숨쉬기 애니메이션을 생략한다. 게임 탭과 여행 지도에서 착장을 확인하고 게임 완료 결과에서 보상·옷장 링크를 볼 수 있다.

## 경제와 보상
- 처음 생성하는 옷장에 선물 100P, 기본 무료 4아이템. 시작 선물을 게임 수익처럼 표현하지 않는다.
- 여행 첫 통과 80P/스테이지·날짜별 도전 첫 통과 50P/각 새 20수 판 완주 40~80P(40+min(40,floor(score/1000)*5))/기믹 판 완주 50P.
- 완료한 엔진 상태를 검증한다. 진행 중/실패 상태나 점수만 담은 일반 teum-game-finished 이벤트로는 지급하지 않는다. 일반 7×7 보관함 게임은 이번 보상 대상이 아니다.
- journey:level, stage:id, daily:date, score:seed, lab:seed를 claim ID로 저장한다. 같은 판 재시작·새로고침·결과 재진입은 재지급하지 않는다. 새 20수/기믹 seed는 새로운 완주 보상을 받는다. 이미 저장된 완료 결과도 이번 옷장에서 처음 읽을 때 1회 받을 수 있고, 기존 전체 통과 기록을 임의로 일괄 포인트로 바꾸지 않는다.
- 구매는 가격과 보유 여부·잔액을 최신 지갑에서 검사한다. 사기만 하고 착용하지 않은 아이템은 옷장에 남으며 착용 버튼은 별도다. 구매/소비/장비/claim을 한 JSON에 기록해 부분 차감과 별도 원장 불일치를 피한다.

## 저장과 한계
키는 teum-avatar-v1이다. 기존 퍼즐/생활/재무 저장 키는 수정하지 않는다. 입력/출력 모두 소유권·장비 슬롯·지출/수익 합계·중복 영수증을 검증한다. 손상 자료는 보존하고 구매를 비활성화한다. 저장 실패 시 이전 착장/잔액은 유지한다. 결과를 다시 열면 미저장 보상을 재시도할 수 있다.

지원 브라우저에서는 Web Locks로 같은 origin의 여러 탭에서 지갑 변경을 직렬화한다. Web Locks 미지원 환경은 동기적인 최신값 읽기/쓰기 fallback이며, 서버 수준의 탭 간 트랜잭션이나 부정 조작 방지를 보장하지 않는다. 이 포인트는 브라우저 전용 게임 재화이며 현금 구매·환전·거래·공유 서버가 없다. 로그인/기기 동기화나 유료 재화 도입 전 서버 원장으로 이전해야 한다.

아이템은 avatar-data.mjs 카탈로그에 추가한다. 저장된 아이템 ID와 기존 가격/무료 기본 아이템을 변경하지 않는다. 가격을 변경하려면 이전 구매 영수증을 보존하는 버전 이관을 먼저 설계한다. 새 형태는 avatar-art.mjs의 해당 부위 레이어에 추가한다. 보상은 avatar-reward-core.mjs, 저장은 avatar-store.mjs, 게임 연결은 avatar-rewards.mjs로 분리한다.

## 검증
- avatar.test: 22개 아트/카탈로그, 소유권/부위/구매/정확한 차감/중복 구매/꾸미기/잔액 부족, 실제 엔진 종료 상태별 보상, 중복 완료, 저장 재진입, 손상/차단/용량 실패 시 원본 보존, 외부 리소스 없는 SVG.
- avatar-browser: 320/360/390/1200px 미리보기→구매→착용→벗기/옷장/무료 피부·표정/새로고침, 실제 여행 판 완주 후 보상/결과/새로고침·재시작 중복 방지, 여러 탭 동시 구매/동일 보상, 손상 저장 보존, 가로 넘침.
- 기존 점수/기믹 완주와 여행/지도/집중 모드 회귀를 확인한다. 실제 휴대폰 터치와 꾸미기 만족도는 사용자 체험으로 확인한다.
