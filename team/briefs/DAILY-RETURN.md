# 매일 돌아오는 작은 틈

## 기획
- 문제: 읽을거리 3편과 무작위 게임만으로는 다음 방문 때 기대할 새 경험이 부족하다.
- 가설: 날짜별 읽기·퀴즈·실천, 개인 기록 회고, 게임의 일일 목표가 재방문 이유가 될 수 있다. 실제 재방문 효과는 아직 검증하지 않았다.
- 출근길: 오늘의 1분 → 한 문제 → 실천 하나 고르기.
- 퇴근길: 한 줄 기록 → 최근 기록 회고 → 게임 한 판.
- 직접 작성한 14일 콘텐츠를 한국 날짜 기준으로 순환한다. 새 기사나 매일 새로 작성한 콘텐츠로 표시하지 않는다.
- 읽기/퀴즈/실천 3가지를 완료하면 정원의 표시가 바뀐다. 현금 보상이나 순위는 없다. 연속 방문을 놓쳐도 기존 기록이 사라지지 않는다.

## 디자인
- 첫 화면에서 날짜·출퇴근 모드·오늘 할 일을 확인한다.
- 기존 초록·따뜻한 배경을 유지하고 저녁 모드에서는 기록 카드를 퀴즈보다 먼저 배치한다.
- 7일 정원은 최근 활동일을 표시하며 방문자 수를 흉내 내지 않는다.
- 읽기 완료, 퀴즈 해설, 저장 성공/실패, 미저장 기록, 삭제 상태를 구분한다.

## 개발
- daily-core.mjs: 한국 날짜·콘텐츠 순환·저장 데이터 검증·최근 90일치 보관.
- daily-content.mjs: 직접 작성한 콘텐츠 14편과 퀴즈·실천·기록 질문.
- daily.mjs / daily.css: 화면·동작·브라우저 저장.
- teum-daily-v1 키에만 새 기록을 저장한다. 기존 자산·최고점·게시판 키는 유지한다.
- 하루 퀴즈는 첫 답과 해설을 저장한다. 실천은 취소할 수 있다. 한 줄 기록은 날짜별 수정·삭제할 수 있다.
- 게임 한 판 종료 이벤트로 오늘 최고점을 갱신한다. 동일 퍼즐이나 공용 순위는 제공하지 않는다.
- 외부 소식의 게시일과 수집 시각을 구분한다.
- 하루가 바뀔 때 미저장 한 줄을 덮어쓰지 않는다. 작성 중인 날짜에 저장한 뒤 오늘 콘텐츠로 전환한다.
- 기록은 이 브라우저에만 저장한다. 외부 행동 분석·알림·인증은 추가하지 않는다.

## 검증
- node tests/daily.test.mjs: 한국 자정, 연도·윤년 경계, 콘텐츠 순환, 저장 데이터 제한, 완료 상태, 퀴즈 잠금, 입력 유지, 저장 실패, 일일 최고점 확인.
- 기존 게시판 코드 검증: 글·댓글·검색·삭제·새로고침 유지·텍스트 렌더링 확인.
- tests/daily-browser.cjs: GitHub Actions에서 360px/390px 실제 Chromium UI를 검사하고 스크린샷 보관.
- 클라우드 내부 미리보기는 relay readiness timeout, 공유 브라우저는 sandbox 초기화 오류로 실행되지 않았다. CI 브라우저 검증과 실제 휴대폰 검증은 구분한다.

## 출시 후 확인할 것
- 대표가 1주 사용하며 어느 모드를 열었는지, 읽기·실천·기록 중 계속 쓰는 기능과 불편을 기록한다.
- 콘텐츠 반복 주기가 짧게 느껴지는지 확인한 뒤 콘텐츠 추가 또는 주제 선택을 결정한다.
- 광고·유료화·사용자 추적은 이 작업에 포함하지 않는다.
