# パズル演出改善 / 목표 수집 퍼즐

사용자 요청으로 FIRE 생활 글 자동화는 일시 중지했다. 다른 예약과 GitHub 데이터 갱신 작업은 변경하지 않았다.

규칙/난수/점수/저장 형태는 유지하고 docs/puzzle-fx.mjs에 표현만 분리했다. 매치 팝·색 파편·점수/연쇄 표시·특수 조각 번개/폭발·얼음 통계 반응·실제 지운 칸 기반 낙하·승리 도해를 추가했다. 효과음은 외부 파일 없이 Web Audio로 짧게 합성하며 기본 OFF, 사용자 버튼 입력 후에만 켠다. 별도 추적이나 외부 데이터 전송은 없다.

포인터 드래그로 이웃 조각을 교환하고 기존 클릭/키보드도 유지한다. touch-action:manipulation과 핀치 확대를 유지하므로 모바일 세로 드래그는 브라우저 스크롤로 취소될 수 있다. 두 조각 탭은 항상 제공한다. 움직임 줄이기에서는 파편/낙하/큰 움직임을 생략하고 짧은 텍스트 피드백을 유지한다. 화면 이탈/재시작 때 파편·타이머·효과 애니메이션을 정리한다. 재생 효과음은 짧고 화면 이탈 시 오디오 컨텍스트를 중지한다.

홈에 게임 바로가기 추가. 마지막 스테이지 뒤 오늘의 도전, 날짜 도전 뒤 스테이지로 연결해 계속 게임할 수 있게 했다.

단위검증: puzzle.test / puzzle-polish / puzzle-improvements 통과. 로컬 Chromium 320/390/1200px, 모션 일반/줄이기에서 가로 드래그 1회 교환·중복 클릭 방지·되돌리기·정답 경로 점수 일치·클리어·오디오 토글·이미지 없는 화면 가로 넘침·이탈 시 파편 제거·JS 오류 없음 확인. 기존 normal-motion 키보드 포커스/방향키/연출 중 재시작/취소/이탈 테스트 통과. 실제 휴대폰 사운드/촉감/조작 만족도는 후속이다. 새 브라우저 검사는 전체 CI에 포함한다.
