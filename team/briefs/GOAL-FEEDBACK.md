# 목표 피드백과 재도전

## 문제와 범위
스테이지의 수집/얼음/특수 미션을 각각 언제 끝냈는지 구별하기 어렵고, 실패 결과가 실제 남은 목표와 관계없는 일반 문구를 보여줬다. 이미 있던 한 수 되돌리기는 결과 모달 밖에 있어 마지막 수를 바로 바꾸기 어려웠다. 다음 작업으로 게임의 목표 전달과 재도전 흐름을 개선한다.

## 구현
- `puzzle-objectives.mjs/css`에서 실제 config/state의 목표를 읽는다. 수집·얼음·미션이 끝나면 체크와 색상을 함께 표시하며, 프레임 중 처음 달성한 목표에만 짧은 반응을 준다. 재시작/되돌리기/다른 판에서는 달성 표시를 다시 계산한다.
- 남은 이동 1~3수에는 별도의 작은 안내와 이동 수 강조를 표시한다. 시간 제한·카운트다운·자동 이동은 없다. 점수판에도 남은 수는 안내하지만 수집/얼음/미션 결과표는 표시하지 않는다.
- 결과창에서 각 목표의 실제 진행량과 부족분을 표시한다. 미션이 남으면 해당 특수 조각의 만드는 법/조합법, 얼음이 남으면 얼음 자리 공략을 안내한다. 실패 문구를 별 크기로 표시하던 문제도 정리했다.
- 실패 후 유효한 undo가 있을 때 결과창의 첫 버튼으로 마지막 한 수를 복원한다. 기존 undo만 쓰고 모달을 닫은 뒤 보드에 포커스를 돌린다. undo가 없으면 같은 판 재시도가 주 동작이다. 승리 결과는 다음 판 진행을 주 동작으로 유지한다.
- 미션 힌트는 실제 `applyMove` 결과가 미션 횟수를 늘리는지 확인해 설명한다. 나머지는 기존 수집/얼음/특수 힌트를 유지한다.
- 게임 엔진·난수·점수·별·보상·기존 저장 형식은 변경하지 않았다. 백업/복원·DB는 이번 범위에 없다.

## 검증
- `tests/puzzle-objectives-browser.cjs`: 엔진에서 실제로 진행해 만든 실패판 사용. 360px 일반 모션, 390px 모션 줄이기, 844×390 가로 집중 모드에서 목표별 부족분, 3수 안내, 결과 모달에서 한 수 복원, 재열기, 실패 시 보상/클리어 미지급, 번개 미션 힌트, 재시작의 달성 표시 초기화, 점수 모드 구분, 가로 넘침과 JS 오류 검사.
- 기존 puzzle/journey/improvements/polish/score/burst 단위 검사와 실제 터치/PNG/모션/효과/집중/점수 브라우저 검사로 관련 회귀를 확인한다.
- 실제 휴대폰의 촉감과 재미는 사용자 체험으로 확인한다. 공개 배포 성공은 해당 커밋의 Pages 실행 결과로 별도 확인한다.
