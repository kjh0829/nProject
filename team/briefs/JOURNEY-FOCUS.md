# 집중 모드와 별빛 배달 여행

사용자 목표: 게임에 집중하고, 매판 점수 도전 외에도 이어서 진행할 이유를 만든다.

## 경험
- 일반/스토리/기믹 게임의 집중 버튼은 사이트 메뉴·도움말·스테이지 선택을 숨기고 판·목표·이동·필수 버튼·결과를 보여준다. 해제 버튼과 Escape로 복귀하고 게임 밖으로 이동하면 해제한다. 다음 여행 판으로 갈 때는 집중을 유지한다. 작은/가로 화면은 조작을 지나치게 줄이지 않고 스크롤을 허용한다. 핀치 확대를 막지 않는다.
- 지원 브라우저만 전체화면 버튼을 표시하고 사용자 클릭에서 requestFullscreen을 호출한다. 실패하면 집중 모드를 유지하며 상태를 표시한다. 브라우저 API 지원과 실제 iPhone/Android 전체화면은 별개이며 실제 기기 검증을 주장하지 않는다.
- 새 #journey 지도: 귤빛 골목 → 유리 온실 → 밤하늘 정거장, 3지역×5판. 편지 배달부 모아와 새 두리의 창작 이야기·직접 작성한 벡터 일러스트. 각 판 목표 수집/얼음, 개별 배치/이동 제한. 모두 4종+연쇄 프로필, 기존 번개/폭탄/무지개만 사용한다. 로켓 등 실험 기믹을 강제하지 않는다.
- 이전 판 통과 후 다음 판 해금, 별/최고 점수/최소 이동, 각 지역 5판 통과 후 짧은 결말, 완료 판 재도전. 하트·시간 대기·유료 추가 이동은 넣지 않는다.

## 참고와 구분
Candy Crush 공식 도움말의 지도에서 레벨 선택→목표 확인→제한 내 목표 달성, 별 기록의 익숙한 흐름을 참고했다. 이름·대사·맵·아트는 새로 작성했다.

## 데이터/검증
- 별도 키 teum-journey-v1, 기존 teum-puzzle-*와 자산/식사/선택극 데이터 보존. 스토리 상태는 별도 mode/level/seed와 목표로 검증하며 일반 슬롯에 들어가지 않는다. 진행/undo/restart, 중복 결과, 잠긴 주소, 손상/차단/용량 오류를 처리한다.
- journey.test: 15판 모두 결정적인 합법 해답, 목표/별, 순차 해금, 저장 격리와 실패 보존.
- journey-focus-browser: 320/360/390px 세로와 844px 가로, 잠긴 주소/진행/undo/새로고침/다음 해금/집중 유지·해제/화면 맞춤/기믹·점수 집중/전체화면 거절 fallback.
- 기존 퍼즐·점수·기믹·연쇄·저장 회귀도 확인한다. 실제 기기의 터치/음질, 재미, 모바일 브라우저 native 전체화면은 후속 실사용 확인 대상이다.
