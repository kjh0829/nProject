# 알찬끼: 식사 중심 방향 전환

## 브레인스토밍
사용자 관찰: FIRE 관심층은 적은 돈으로 알차게 먹은 한끼에 뿌듯함을 느끼고, 다른 사람도 그런 사례를 즐겨본다. 현재 사이트의 퍼즐·기록·계산기보다 식사라는 구체적인 방문 이유가 선명할 수 있다. 이는 검증할 가설이며 실제 사용자 규모나 재방문 개선을 확인한 결과는 아니다.

| 방향 | 가치 | 이번 적용 |
|---|---|---|
| 가성비 한끼 발견 | 오늘 먹을 메뉴를 빠르게 고르기 | 음식 중심 홈·재료 검색·가격/시간 필터 |
| 한끼 자랑 | 내 식사의 작은 성취를 기록 | 사진·메모·재료비·조리법을 내 브라우저에 저장 |
| 저장하고 따라 먹기 | 다음 식사 때 재방문 | 저장한끼·먹어본 한끼·내 기록 분류 |
| 신뢰할 수 있는 비용 | 숫자만 싼 사례를 줄이기 | 사용량 원가·1인분·포장 구매비 구분 |
| 함께 반응하기 | 다른 사람에게 인정받는 즐거움 | 공유 DB·인증 연결 전까지 보류. 가짜 반응·봇 사용자 없음 |

가칭은 알찬끼. FIRE만 아는 말 대신 자취생·직장인도 이해할 식사 이름과 가격을 전면에 둔다. 기존 퍼즐은 쉬는 틈으로 보존한다.

## 구현 범위
- 기본 홈: 식사 일러스트·1인분 사용량 원가·시간·재료 중심 카드 4개.
- 예시는 직접 작성한 레시피와 가정 단가다. 시장 조사나 실제 이용자 글로 표시하지 않는다.
- 음식 이미지는 이 작업에서 생성한 AI 예시 일러스트다. 사용자 사진과 다른 레이블을 표시한다.
- 검색은 메뉴·재료·내용을 찾고 계란/달걀 표기를 함께 처리한다. 3천 원 이하·10분 이내·가격/시간 정렬 지원.
- 상세: 분량 변경, 재료별 사용량 원가, 처음 포장 단위로 살 때의 비용, 조리법과 작은 팁.
- 저장함: 저장한끼·먹어본 한끼·직접 작성한 기록. 집계는 내 브라우저 데이터이며 공용 반응이 아니다.
- 기록: 제목·닉네임·인분·시간·비용 기준일·재료별 사용량 비용·조리법·사진. 최대 20개.
- 사진은 JPG/PNG/WebP 4MB 이하를 브라우저에서 줄여 저장한다. 외부 업로드 없음. 저장 실패 시 폼을 유지한다.
- 사용자가 공유 버튼을 누르면 예시는 상세 링크, 개인 기록은 레시피 텍스트와 홈 링크를 공유한다. 개인 상세 URL이 다른 기기에서 열린다고 표현하지 않는다.

## 계산 기준
- 예시: 포장 가격 × 사용량 / 포장량을 재료별 합산. 원래 인분으로 나누고 10원 단위 반올림한다.
- 처음 전부 구매 비용은 필요한 포장 수를 올림해 계산한다. 한끼 사용량 원가와 다르다.
- 개인 기록은 총 인분에 쓴 재료비를 입력받아 1인분 비용을 계산한다. 포장 단가가 없으므로 처음 구매 비용을 추정하지 않는다.
- 밥·기름·양념을 포함하도록 안내한다. 조리 에너지·도구·배송비는 제외하며 미리 지은 밥 기준 시간이다.
- 예시 단가와 사용자 입력 금액은 영수증 검증된 가격이 아니다. 영양 수치나 건강 효과를 꾸며 넣지 않는다.

## 구조와 데이터
- meal-data.mjs / meal-core.mjs / meals.mjs / meals.css.
- 저장 키 teum-meals-v1, 기존 금융·게시판·퍼즐·이야기 저장 키 보존.
- 화면: #home, #saved-meals, #meal-compose, #meal. 기존 놀이터는 #arcade, 이전 기능의 주소 유지.
- 기존 navigation의 주소별 스크롤 복원을 재사용한다.
- 공유 DB·계정·실제 댓글/공감·영수증 검증·자동 분석 수집은 추가하지 않는다.

## 검증
- tests/meals.test.mjs: 인분과 분량 계산, 포장 구매 수 올림, 검색·필터, 날짜·사진 검증, 저장 중복/한도/손상/용량 실패.
- tests/meals-browser.cjs: 360px/390px/1200px에서 검색→상세→저장/먹어봄→사진 포함 기록→새로고침→텍스트 공유→삭제→기존 놀이 접근, 입력 텍스트 렌더링과 저장 실패 시 폼 보존.
- 기존 일일 기록·퍼즐·이야기 검증도 유지한다. 이전 홈을 #arcade로 명시해 보조 기능으로 확인한다.
