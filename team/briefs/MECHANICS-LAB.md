# 특수 기믹 도전

사용자가 제안된 모든 추가 요소의 구현을 승인했다. 기존 모드에 새 규칙을 강제로 섞지 않고 #lab에 함께 플레이 가능한 독립된 20수 모드로 묶었다. 게임 탭의 첫 카드와 홈 새 기믹 링크에서 열며 일반 20수/스테이지로도 돌아갈 수 있다. 그림/효과는 직접 작성한 벡터와 CSS/Web Audio이며 외부 게임 자산/유료 API는 추가하지 않았다.

## 특수와 조작
처음부터 로켓/연결/회오리/성장 각 한 개를 제공한다. 추가 생성은 2×2 정사각형→유도 로켓, 6개 직선→연결 폭탄, 연결된 6칸 이상 T/L→회오리, 2연쇄 이후 4개 직선→성장 폭탄이다. 기존 번개/폭탄/무지개도 나온다. 겹친 생성은 6직선/5직선/정사각형/교차/4직선 순으로 판정한다.

로켓은 상자/사슬/특수 조각을 우선 찾아 한 칸을 타격한다(결정적 우선순위와 위치 동률 처리). 연결 폭탄은 먼저 조각을 누르고 다른 임의 칸을 누르면 두 점의 직선 경로를 제거한다. 회오리는 주변 고정되지 않은 칸의 배치를 한 단계 회전시킨다. 성장 폭탄은 옆 매치로 최대 3단계까지 커지고 3×3/5×5/7×7 범위로 폭발한다. 범위는 보드 안으로 제한한다. 기믹 모드 내 무지개 변환은 새 특수 종류와도 연동하되 상자 뒤의 보이지 않는 조각은 변환하지 않는다. 기존 특수 종류끼리의 강화 조합은 유지한다.

## 지도와 에너지
상자 4칸(각 내구도2), 사슬 2칸(내구도1), 포털 한 쌍과 컨베이어 한 줄이 있다. 상자는 매치에서 제외되고 직접/옆 제거로 프레임마다 한 번 손상된다. 사슬은 직접 교환과 낙하를 막지만 해당 조각의 매치/폭발로 제거된다. 장애물은 고정이고 중력은 고정 칸 사이 구간별로 계산한다. 컨베이어 회전과 포털 내용 교환은 유효한 이동마다 한 번만 실행되고 새 연쇄를 만들 수 있다. 스킬에는 지도 자동 이동이 없다.

매치/특수 발동으로 에너지100을 모으면 연결 빔(시작·끝 두 칸), 회오리(중심 칸), 성장 폭탄 설치(일반 칸) 중 선택한다. 스킬은 이동을 차감하지 않으며 자기 연쇄로 에너지를 회수하지 못한다. 취소/잘못된 위치는 무료다. 도중 스킬의 undo는 점수·에너지·지도·난수·행동 수까지 이전으로 복원한다.

## 정산·저장
20번째 유효 이동 후 남은 특수를 순서대로 처리하고 일반 연쇄를 포함한 보너스를 계산한다. 보너스 중 새 특수를 만들지 않으며 각 패스는 특수를 최소 하나 소모하므로 유한하게 끝난다. 결과는 엔진에서 먼저 한 번 계산해 저장하며 UI는 이를 재생한다. 이탈/새로고침이 정산을 중복 지급하지 않는다. 최근10개 시드별 최고와 전체 최고는 teum-puzzle-lab-v1에만 저장한다. 일반 점수/스테이지/날짜/금융 기록을 수정하지 않는다. 같은 시작판 재도전과 취소, 새 판, 텍스트 결과 공유를 제공한다. 초기 생성·리필·이동·스킬·정산은 시드와 행동으로 재현된다. 손상/차단/용량 부족이면 원문을 보존하고 저장 실패를 표시한다.

## 표현
새 모드에서 로켓의 곡선 비행, 연결 빔, 실제 회전하는 조각과 회오리, 성장 단계, 상자 금/사슬, 포털과 벨트 이동, 보너스 문구를 구분한다. 기존 모드에도 폭발 전 130ms의 확대/예고와 짧은 정지, 목표/점수로 날아가는 수집 궤적, 연쇄별 음정/파편 반경/팝업 강조를 적용했다. fx는 보드/화면 ID 범위를 받아 두 게임의 효과/오디오를 분리한다. 기본 음소거·사용자 토글·화면 이탈 정리와 모션 줄이기를 유지한다. 반복 점멸을 추가하지 않았다.

## 검증
lab.test.mjs: 각 생성 패턴, 로켓 우선 타깃, 먼 연결, 회전, 성장, 장애물, 지도 이동, 이동 소모 없는 스킬, 보너스 점수 합계, 완료 후 입력 거절, 분리/실패 저장과 80개 시드의 20수+스킬 완주·원본 불변·시드 재현.

lab-browser.cjs: 320/390/1200px 실제 20수와 세 스킬 사용, undo/restart/취소·새로고침·다음 판·최고 기록/키 분리·가로 넘침/오류 없음. 일반 모션 390px에서 로켓, 연결 빔/회오리/성장, 보너스 연출과 새로고침 중복 정산 방지 확인. 재시작/이탈 시 움직이는 객체 정리 및 손상 저장 원문 보존. 결과/효과 스크린샷 확인.

기존 puzzle/polish/improvements/navigation/score-mode/specials 단위, 기존 모션/퍼즐/점수/메뉴 브라우저 회귀를 함께 실행한다. 실제 iOS/Android 음량·성능과 난이도/재미 평가는 후속 실사용으로 확인한다. 자동 글 발행 일시 중지는 유지한다.
