# 게임·꾸미기 중심 메뉴 정리

## 문제와 동작
홈과 게임에 점수/여행/오늘/연습/실험 시작점이 나뉘어 있고 꾸미기는 하위 기능처럼 보였다. 상단·하단을 홈/게임/꾸미기/내 기록으로 통일한다.

- 홈은 실제 저장 상태로 현재 스테이지 시작/이어하기, 현재 캐릭터, 해당 스테이지 첫 보상(80P, 이미 수령 시 잔액)을 표시한다.
- 게임은 현재 스테이지와 전체 지도, 별도의 빠른 한 판을 우선 제공한다. 날짜별/연습 판과 기믹 도전은 접힌 보조 메뉴다.
- 꾸미기는 기본 옷장이다. 초기 고정 디자인은 하단 ‘캐릭터 디자인 참고’에서 연다. 기존 reference 주소도 유지한다.
- 내 기록은 실제 클리어/별/의상/포인트를 표시한다. FIRE·월예산·생활 기록·발행 글은 ‘생활 도구·읽을거리’, 식사/퀴즈/일기/게시판은 ‘이전 기록 보관함’에서 연다.

## 보존 범위
기존 해시 주소와 모든 DOM ID, 게임 규칙·의상 원화·가격·저장 키를 보존한다. 새 요약 모듈은 검증된 데이터만 읽으며 초기화나 이관을 수행하지 않는다. 참조 원화와 주 메뉴의 aria-current 관리는 분리한다.

## 검증
21개 단위 검사와 기존 내비게이션/게임/아바타 회귀 및 site-review-browser에서 320/360/390/1200px 4개 탭, 실제 한 수 플레이 후 홈 이어하기, 저장 원문 보존, 생활 도구·예전 보관함·직접 주소·터치 크기·가로 넘침을 확인한다. 실제 플레이 후 돌아오면 이어하기로 바뀌고, 스테이지 1을 클리어한 저장 상태는 스테이지 2로 연결되는지 확인했다. 접힌 메뉴로 이동한 기존 QA는 해당 메뉴를 열고 동작을 검사한다.
