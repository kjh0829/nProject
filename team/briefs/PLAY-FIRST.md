# 첫 3분의 재미: 퍼즐과 선택극

## 범위
사용자가 제로 베이스 검토 후 구현을 요청했다. ‘습관 장치보다 핵심 즐거움을 먼저’라는 가설을 첫 화면과 두 개의 체험으로 구현한다. 재미와 재방문 효과는 아직 실제 사용자에게 검증하지 않았다.

## 기획·디자인
- 기본 탭은 놀이터. 큰 퍼즐 시작 버튼, 1분 선택극, 5개 스테이지 바로가기 순서로 구성한다.
- 메뉴는 놀이터 / 퍼즐 / 이야기 / 더보기로 바꾼다. 이전 계산기·브라우저 기록·체험 게시판·자유 매치는 더보기와 홈 링크에서 유지한다.
- 남색 보드, 과일 조각, 번개·폭발 피드백으로 놀이를 먼저 보여준다. 모션을 줄인 환경을 존중하고 핀치 확대는 유지한다.
- 짧은 발견으로 직접 그린 에빙하우스 착시를 추가한다. 원 두 개가 같은 크기라는 설명과 출처를 제공한다.

## 게임
- 6×6 매치, 5개 스테이지. 목표 조각 수집과 고정 위치 얼음 제거.
- 4개 매치로 가로 번개, 5개 이상으로 주변 폭발 조각 생성. 이웃 조각과 바꾸거나 다른 매치가 닿으면 발동한다.
- 같은 스테이지는 같은 시작 보드와 채움 순서를 사용한다. 무효 이동은 차감하지 않는다.
- 날짜별 도전은 시뮬레이션으로 해답을 찾은 seed를 선택한다. 같은 날짜에 모두 같은 문제를 제공하며 재도전 가능, 공용 순위는 없다.
- 마지막 플레이 판의 진행을 브라우저에 저장하고 홈에 이어하기를 제공한다. 스테이지별 통과 기록과 일일 최고 결과는 별도 저장한다.
- 결과와 동일 퍼즐 링크를 공유한다. 브라우저 공유·클립보드 실패 시 직접 복사 가능한 텍스트를 제공한다.

## 이야기
- 창작 1화 ‘퇴사를 결심했더니 재택 제안이 왔다’.
- 선택 두 번으로 네 개 결말. 중간 선택, 발견한 결말을 브라우저에 저장한다.
- 이전 선택·처음부터 다른 선택·결말 공유를 제공한다. 다음 회차 공개 일정은 약속하지 않는다.

## 데이터
- 신규 저장 키: teum-puzzle-run-v1, teum-puzzle-progress-v1, teum-story-v1.
- 기존 목표·일기·게임 최고점·체험 게시판 저장 키는 유지한다.
- 인증·공유 DB·분석 수집·광고·유료화는 추가하지 않는다.

## 검증
- node tests/puzzle.test.mjs: 다섯 스테이지 해답, 무효 이동, 특수 조각, 얼음, 결정성, snapshot, 무작위 시뮬레이션, 날짜 도전 샘플, 이야기 네 결말.
- 기존 daily.test.mjs와 게시판 검사 유지.
- GitHub Actions의 360px/390px 실제 Chromium 흐름에서 게임 통과·중간 복원·결과 공유 fallback·날짜 도전·네 결말·화면 넘침을 확인한다.
- 공유 클라우드 브라우저는 sandbox 초기화 오류로 실행되지 않아 CI를 브라우저 검증 경로로 사용한다.
