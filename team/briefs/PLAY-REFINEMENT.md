# 재도전 흐름 개선

## 검토한 문제
- 단일 teum-puzzle-run-v1 키 때문에 다른 스테이지를 여는 순간 이전 판이 덮어써졌다.
- 힌트는 목표·얼음과 관계없이 첫 유효 매치를 알려줬다.
- 잘못 고른 한 수를 다시 시도하려면 처음부터 시작해야 했다.
- 통과 기록만 있어 같은 스테이지에서 더 잘해볼 기준이 부족했다.
- 발견한 결말도 처음부터 선택해야 다시 읽을 수 있었다.

## 구현
1. teum-puzzle-saves-v2에 스테이지 5개와 최근 14개 날짜별 진행을 독립 저장한다. 기존 V1 진행은 메모리에서 읽어 새 저장에 이관하며 기존 키는 덮어쓰지 않는다. 손상된 V2 저장은 자동으로 덮어쓰지 않는다.
2. 바로 전 이동 1회 되돌리기. 이동·보드·얼음·점수·채움 난수 상태를 함께 복원하고 되돌리기 자체도 저장한다. 통과한 판은 기록을 유지하며 되돌릴 수 없다.
3. 목표 조각·얼음 제거·특수 조각 생성을 우선하는 힌트로 변경한다. 힌트는 이동을 쓰지 않는다.
4. 남은 이동 절반 이상 3성, 1/4 이상 2성, 나머지 통과 1성. 현재 판의 별, 개인 최고 점수, 최소 이동을 표시한다. 공용 순위나 참여자 지표는 추가하지 않는다.
5. 발견한 이야기 결말을 눌러 바로 다시 읽는다. 이미 본 두 번째 선택에는 표시를 붙이고, 수집 기록은 유지한다.

## 데이터와 한계
- 기존 금융 목표·게시판·일기·이야기 저장 키는 유지한다.
- 퍼즐 슬롯의 한 수 전 상태까지 함께 저장한다. 동시에 여러 단계의 되돌리기를 제공하지 않는다.
- 저장 공간·권한 오류는 화면에 표시하고 현재 판은 계속 즐길 수 있다. 브라우저 사이의 동기화는 없다.
- 별 기록은 개인 목표다. 재미나 재방문이 실제로 증가했는지는 아직 검증하지 않았다.

## 검증
- tests/puzzle-improvements.test.mjs: 독립 슬롯, 이어하기 선택, V1 이관, 되돌리기 저장·검증, 일일 슬롯 14개 제한, 손상/차단/용량 초과 저장소, 별 경계값, 목표 중심 힌트, 결말 경로 확인.
- tests/puzzle.test.mjs: 기존 5개 스테이지 해답·특수 조각·얼음·결정성·저장 상태 검증 유지.
- tests/playground-browser.cjs: 360px/390px에서 스테이지 왕복·새로고침·힌트·되돌리기·통과·별·결말 재열기를 실제 Chromium에서 검증한다.
