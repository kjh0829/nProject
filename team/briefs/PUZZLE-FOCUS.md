# 퍼즐 집중과 다음 개선 검토

사용자가 재미없다고 평가한 선택극의 홈 카드·게임 탭 카드/링크·퍼즐 상단 링크를 제거했다. 기록 허브의 게임 설명도 퍼즐/날짜 도전으로 바꿨다. 게임 허브에서 이야기 기록을 읽는 의존도 제거했다. 과거 story 해시와 저장 데이터는 손상시키지 않는다. 기존 선택극 회귀 검사는 주소 직접 접근으로 유지하고, 게임/홈에 재홍보 링크가 없는지 확인한다.

## 검토
현재 5개 스테이지는 고정 시작판/채움 순서이며 재도전은 정답 경로와 별 수를 개선하는 구조다. 날짜별 도전은 있지만 짧은 판을 여러 번 즐기려면 새 판의 다양성과 점수 경쟁이 부족하다. 이미 파편/낙하/연쇄/오디오를 추가했으므로 다음 우선순위는 표현보다 규칙과 반복 재미다. 실제 사용률/이탈률을 측정한 결론은 아니다.

권장 후속은 20수 점수 모드: 새로운 검증된 시작판, 목표 수집 조기 종료 없이 제한된 이동 안에서 연쇄/특수 조각으로 점수 개선, 기기 내 최고 기록, 즉시 다음 판. 시간 제한 없이 기존 탭 조작을 유지한다. 구현 전 리필 순서 재현/합법 수/점수 일관성/진행 복원을 정해야 한다. 아직 구현하지 않았다.

그다음은 특수 조각끼리 교환의 별도 조합 효과와 선택 전략, 5개 이후 난이도별 스테이지 확장. 높은 난이도를 무작위 막힘이나 광고/결제 장벽으로 대신하지 않는다. 실제 사용자 없는 리더보드/수치도 만들지 않는다.
