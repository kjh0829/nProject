# 게임 판정과 조작 복구 개선

## 확인한 문제
- 한 번의 이동에서 4개 매치와 다른 곳의 특수 조각이 동시에 발동하면, 실제 폭발 범위 밖의 새 번개도 사라졌다. 매치가 없는 유효한 시작 보드로 재현했다.
- 다시 시작 버튼은 즉시 저장판을 덮어써서 잘못 누른 뒤 복구할 수 없었다.
- 연쇄 동안 버튼 DOM을 바꾸고 비활성화하면서 키보드 포커스가 사라졌다.
- 유효 이동도 조각이 즉시 바뀌어 어떤 두 조각이 교환됐는지 피드백이 약했다.

## 수정
- 특수 조각이 실제로 덮은 칸을 별도로 추적한다. 새 조각은 실제 폭발에 닿았을 때만 제거한다.
- 다시 시작 이전 판과 한 수 전 상태를 같은 슬롯의 선택 필드에 보관한다. 다음 유효 이동을 하기 전까지 취소할 수 있고, 새로고침 후에도 복구할 수 있다. 새 판에서 다시 시작을 반복 눌러도 첫 백업을 유지한다.
- 저장 슬롯 검증에 재시작 백업도 포함한다. 기존 슬롯과 저장 키를 유지한다.
- 일반 모션에서 두 조각이 교환되는 120ms 움직임, 무효 이동의 짧은 시각 피드백을 추가한다. 모션 줄이기 환경에서는 교환 애니메이션과 흔들림을 생략한다.
- 연쇄 뒤 보드의 키보드 포커스를 복원한다. 사용자가 다른 탭이나 컨트롤로 옮겨갔다면 포커스를 빼앗지 않는다. 게임을 떠난 동안 판이 끝나도 결과로 강제 이동하지 않는다.

## 검증
- 수정 전 재현: 유효 보드, 초기 매치 0개, 떨어진 특수 조각 1개 발동 시 새 번개 생성 0개/생성 칸 제거. 수정 후 새 번개 1개 유지. 직접 폭발이 닿으면 제거되는 경우도 확인한다.
- tests/puzzle-polish.test.mjs: 동시 특수 조각 회귀, 재시작 백업 저장/검증/복원.
- tests/playground-browser.cjs: 360px/390px에서 재시작→새로고침→취소→기존 보드/남은 이동 복원 확인.
- tests/puzzle-motion-browser.cjs: 일반 모션에서 Enter·방향키 연속 조작, 애니메이션 도중 재시작, 이전 애니메이션의 덮어쓰기 방지, 게임을 떠났을 때 포커스 보호 확인.
- 기존 5개 스테이지의 해답과 저장·일일 콘텐츠 검사를 유지했다. 현재 날짜 기준 지난 14일~이후 6일의 도전 seed가 수정 전후 동일함을 확인했다.
- 실제 iOS/Android에서의 터치 감각과 재미는 후속 체험으로 확인한다.
