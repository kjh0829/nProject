# 소프트 아케이드

사용자가 세 가지 테마 중 권장안을 승인했다. 게임 우선의 따뜻한 놀이터로 홈을 재구성한다. 새로운 수치/사용자/후기를 만들어 넣지 않는다.

## 화면 구성
홈의 지배적 요소는 시간 제한 없는 목표 수집 퍼즐 시작 CTA와 실제 게임과 같은 벡터 조각 일러스트다. 두 번째로 저널/선택극, 다음으로 장보기/FIRE/월예산, 마지막으로 기존 한끼 예시/검색/개인 기록 링크를 유지했다. 5개 주 메뉴는 홈·게임·목표·월예산·기록으로 상하 동일하다. cart/meal-lab/meal은 홈, arcade/challenge/story/play는 게임, 식사 저장/작성/게시판은 기록으로 현재 메뉴를 표시한다. 모든 기존 해시 주소와 저장 키는 유지한다.

## 표현
크림 바탕, 짙은 보라 본문·게임판, 살구색 주 CTA, 연보라 보조 표면을 사용한다. 글꼴은 시스템 글꼴로 외부 폰트 로딩을 추가하지 않는다. 공통 스타일은 soft-theme.css에 마지막 계층으로 분리해 기존 컴포넌트 기능과 분리했다. soft-graphics.mjs의 고정 SVG를 홈/게임/메뉴에 재사용한다. SVG에는 외부 참조/스크립트가 없고 조각의 색만이 아닌 모양과 접근성 이름도 유지한다. soft-theme.mjs는 고정 UI 장식만 렌더링하며 사용자 데이터를 HTML로 삽입하지 않는다. 퍼즐의 정답·난수·조작·효과음·저장은 바꾸지 않았다.

저널 CSS도 동일 색상·가독성·여백을 적용했다. 저널 본문과 개별 도해, 자동 발행 일시 중지 설정은 유지한다. 기존 음식 예시의 AI 이미지/가정 가격 표시는 그대로다. 작은 프로토타입 게임/이야기/금융 자료를 삭제하지 않는다.

## 검증
로컬 Chromium 전체 사이트 320/360/390/1200px 주 메뉴 일치·활성 표시·생활 도구·기록·보관함·가로 넘침·44px 메뉴 타깃 통과. 360/390px 탭 스크롤/뒤로 가기/직접 링크/입력 크기, 360/390/1200px 식사 검색·저장·사진 기록·손상 저장 보존 통과. 퍼즐 320/390/1200px에서 일반/움직임 줄이기 양쪽 드래그·되돌리기·정답 점수·클리어·오디오 토글·이탈 검증 및 기존 모션 중 재시작/키보드 회귀를 실행한다. navigation/puzzle 단위 검사 통과. 390/1200px 홈과 390px 게임 스크린샷을 확인했다. 실제 iOS/Android 기기 사용성은 후속이다.
