# 20수 점수 도전

## 규칙과 접근
사용자가 승인한 반복 플레이 모드다. 홈 주 CTA와 게임 탭 새 카드, 퍼즐의 20수 점수 링크에서 연다. URL은 #challenge?mode=score. 시간 제한 없이 유효 교환 20회로 점수를 모으며 수집 목표를 충족해도 조기 종료하지 않는다. 무효 교환은 이동을 쓰지 않는다. 연쇄/특수 조각 점수는 기존 엔진과 같다. 힌트는 점수/특수 생성 중심이다. 초기판은 매치 없이 합법 수를 보장하며 채움도 시드로 재현한다. 가능한 수가 없으면 이동을 더 쓰지 않고 재배치한다. 판이 다르면 얻기 쉬운 점수도 달라질 수 있다.

## 진행과 결과
score-saves.mjs의 teum-puzzle-score-v1만 사용한다. 진행 하나, 바로 전 한 수, 같은 판 재시작 취소, 라운드 시작 시 최고 기록, 전체 최고 점수와 최근 10개 시드별 최고를 저장한다. 새 판은 새 시드를 사용하고 최고 점수는 유지한다. 같은 판 재도전도 개인 기록에 포함한다. 결과를 다시 열거나 같은 시드를 다시 끝내도 기록이 중복 증가하지 않는다. 종료 후 되돌리기는 잠겨 있으며 같은 판 재도전/새 판을 제공한다. 진행 중 새 판으로 바꿀 때만 기존 진행 교체 확인을 받는다.

별도 최고 기록은 저장된 완료 판 기준이다. 기록은 브라우저 안에만 보관되고 기기 간 동기화나 서버 랭킹은 없다. 손상/저장 차단/용량 부족은 기존 원문을 보존하고 화면에 저장 실패를 알린다. 기존 teum-puzzle-progress-v1, 스테이지/날짜 저장과 사용자 금융 데이터는 건드리지 않는다. legacy 슬롯은 score 스냅샷을 거부한다.

공유 문구는 새로운 판으로의 도전 링크임을 알리고 동일 판 대결처럼 표현하지 않는다. 소리·이펙트·모션 줄이기·키보드·탭/드래그는 기존 방식이다. 점수 결과에는 스테이지 별 평가를 붙이지 않는다.

## 검증
단위 검사: 40개 시드 각 20수 완주, 동일 시드/교환 재현, 매치 없는 시작/합법 수, 조기 종료 없음, 종료 후 입력 거부, 스냅샷, 분리 저장, undo/restart, 최고/최근 기록 중복 방지, 손상/용량 부족 원문 보존. 기존 puzzle/puzzle-improvements/puzzle-polish 검사 통과.

Chromium 320/390/1200px 움직임 줄이기에서 실제 20수 완주, 되돌리기, 새로고침 복원, 같은 판 재시작·취소(새로고침 포함), 최고 기록/결과 복원, 새 시드/다음 판, 기존 스테이지 진입/데이터 분리, 가로 넘침, 오류 없음 검증. 390px 일반 모션에서 새 판 교체 취소/승인도 검증한다. 손상 score 키와 별도 개인 데이터 원문 보존 확인. 기존 정상 모션 키보드/재시작, playground와 사이트 메뉴 회귀 통과. 결과 스크린샷을 확인했다. 실제 휴대폰 체감 재미와 랜덤판 난이도 균형은 후속 검증이다.
